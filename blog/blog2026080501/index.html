2027秋季入学必看：澳门大学教育学硕士申请时间线+专业方向+费用清单

2026/08/05

步肢艺术留学公众号

入学指南

THE 2026世界排名第145位，QS 2027世界排名第267位

——澳门大学。

两年学费17.4万澳门币，CET-6 430分就能申，接受雅思6.0（小分5.5）或托福80分。 不需要GRE，不需要作品集，不强制要求教育专业本科背景。

最关键是——教育学硕士，跟舞蹈生高度适配。

澳门大学教育学院开设的哲学硕士学位（教育学），下设课程与教学、教育行政、教育心理学、幼儿教育与儿童发展等多个专业方向。

舞蹈生选课程与教学方向，可直接将舞蹈教学法、艺术课程设计作为研究课题；选教育心理学方向，可切入舞蹈对儿童心理发展、艺术疗愈等交叉领域；选幼儿教育与儿童发展方向，儿童舞蹈教育、律动与认知启蒙就是天然的研究素材。

1课程概述

澳门大学教育学院开设的哲學碩士學位（教育學） 课程，旨在培养学生在多元教育领域的高級知識和研究技能。通过严谨的课程设计，包括核心研究方法相关科目和專業學習規劃，该课程使学生具备分析和批判性思维能力，以应对复杂的教育挑战。毕业生将具备继续攻读博士学位的能力，或在各种专业教育环境中领导和创新，为教育知识和实践作出贡献。

2申请与入读时间

澳门大学哲学硕士学位（教育学）课程每年分两轮招生：

  • 第一批次的申请时间是从2026年10月3日至2027年1月2日；

  • 第二批次则是从2027年1月3日至2027年3月13日。

2027/2028学年的报名日期为2026年8月3日至2027年4月30日。

需要注意的是，澳门大学采用滚动录取机制，先到先审，这就意味着建议各位申请者尽早提交申请，以免错过最佳时机。

入学时间为每年8月，属于秋季入学，学制为2学年，全日制学习模式。

3专业方向与课程结构

澳门大学哲学硕士学位（教育学）提供了多个专业方向供学生选择，主要包括：

  • 课程与教学（Curriculum and Instruction）

  • 教育行政（Educational Administration）

  • 学校辅导（School Counseling）

  • 科学教育（Science Education）

  • 教育技术（Educational Technology）

  • 中文教育（Chinese Education）

  • 幼儿教育与儿童发展

  • 教育心理学

对于有舞蹈背景的申请者来说，也有特别适合他们的专业方向。例如课程与教学方向，可将舞蹈教学法、艺术课程设计、舞蹈教材开发等作为研究方向，非常适合有舞蹈教学经验的申请者；教育行政方向可研究舞蹈教育管理、艺术机构运营、舞蹈学校政策制定等，为未来从事艺术教育领导岗位做准备。

课程采用“理论 + 实践”的授课方式，毕业要求修满30学分。其中研究方法科目占9学分，需要修3门必修课程；专业科目也是9学分，学生要从专业领域课程中选择3门；论文占12学分，是科研性质的原创书面论文，并且需公开答辩通过。

所有专业方向的学生需修读以下核心科目：

  • 當前教育議題探討（Current Issues in Education）

  • 教育研究的質性方法、資料管理與分析（Qualitative Methods, Data Management, and Analysis in Educational Research）

  • 教育研究的定量方法、資料管理與分析（Quantitative Methods, Data Management, and Analysis in Educational Research）

  • 論文（Thesis）

4申请与语言要求

申请要求：

1. 学历要求：

  • 持有澳门大学认可的学士学位或同等学历；

  • 学士学位学习中达到相当于C+级或更高的总成绩；

  • GPA不低于2.3（4.0制）或平均成绩不低于70分。

2. 其他要求：

  • 具有来自排名有竞争力的大学的学士学位；

  • 具有竞争力的本科GPA；

  • 具备较强的科研潜力和优异的学术成绩；

  • 部分专业方向可能有额外要求（如教育相关背景或经验）。

语言要求方面，如果申请人所获学士/硕士学位之教学语言不是英语，就须提交以下任何一种英语能力证明：

  • 大学英语考试（CET - 6）430分、

  • 雅思（IELTS）总分6.0且各项不低于5.5、

  • 托福（TOEFL）80分（网考）、

  • 英语专业考试（TEM）四级或八级合格。

需要注意的是，托福及雅思考试成绩有效期须为两年内，本科教学语言为英语者可豁免语言要求。

5学制与费用

澳门大学哲学硕士学位（教育学）的学制为2年，是全日制学习模式。

费用方面，年学费为87,000澳门币，课程全额学费（2年）为174,000澳门币，申请费用为250澳门币。

生活费参考约5万人民币/年，2年就读结束总费用约24万人民币。

6选择理由

澳门顶尖学府，国际排名稳步攀升:

  • QS 2027 世界大学排名：全球第 267 位

  • THE 2026 世界大学排名：全球第 145 位

澳门大学作为澳门最具国际影响力的综合性大学，近年排名持续跃升，学位含金量备受国际认可。

✅ 多元专业方向—涵盖课程与教学、教育行政、学校辅导、科学教育等多个领域，尤其适合舞蹈生结合自身专长选择研究方向;

✅ 研究导向培养—30学分制，包含12学分论文，为攻读博士学位奠定坚实基础

✅ 灵活语言要求—接受CET-6、雅思、托福、TEM等多种英语成绩;

✅ 高性价比—两年总学费17.4万澳门币，相较欧美留学更具优势;;

✅ 中文+英文双语授课——降低语言适应门槛，便于舞蹈生快速进入专业学习状态.
